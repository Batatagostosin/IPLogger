# IP Logger

A Python script that retrieves an incoming client IP address, records the detection day and time, and posts the details to a Discord webhook.

> **Disclaimer:** Use this script only on systems and with users where you have explicit permission, and follow applicable privacy and data-protection rules.

## Features

- Captures the client IP address.
- Records the day and timestamp of detection.
- Sends formatted log notifications to a Discord webhook URL.

## Requirements

- Python 3.x
- Dependencies listed in `iplogger.py` (for example, `requests` or `flask` if serving an HTTP endpoint)
